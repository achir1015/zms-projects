資料助秘專案彙整

GitHub 專案集中管理 · 主題、版本、上架、影片與六平台進度一頁掌握

把 GitHub 上的每個專案整理成卡片：README 大標題就是專案主題，最新發佈版本與下載檔、App Store／Google Play／ 示範影片／線上版連結自動找出來；再用分類頁簽、平台進度總表與待辦事項管理開發進度。

主要功能

sync
一鍵彙整 GitHub專案清單、README、最新發佈版本；ETag 快取，次數用完改用發佈頁查詢（不扣次數）
title
README 大標題＝主題卡片最上面顯示 README 第一個大標題，例如「A13input A13輸入資料」
smart_display
播放媒體README 裡的 mp4、GitHub 上傳影片、YouTube 自動列成播放按鈕
folder_special
分類頁簽自訂分類、顏色與順序；依名稱規則自動分類
grid_view
六平台進度Windows、Mac、線上版、iPhone、iPad、Android；依發佈檔自動標示已發佈
admin_panel_settings
MariaDB＋使用者權限七項功能 × 無／查詢／維護、操作紀錄、備份還原、程式內更新

線上版

不用安裝，手機、平板、電腦用瀏覽器就能看所有公開專案。

language
專案彙整線上版搜尋、分類頁簽、篩選（發佈版本／App Store／Play／影片／線上版）、平台進度總表、README 與影片播放
publish
資料怎麼更新桌面版「彙整 GitHub → 發佈線上版」把公開專案送到這裡；線上版的「即時更新」可再向 GitHub 取最新星星數與說明
lock
不公開的資料不會送出私人專案、便利貼備註、待辦事項、負責人與帳號權限只留在自己的資料庫

公司內的線上版

便利貼、待辦、平台進度的維護都在自己電腦的 MariaDB，要在其他電腦、平板上編輯，就由這台電腦提供網頁服務。

開啟桌面版「系統管理 → 版本更新與捷徑」→ 打開「公司內的線上版」。畫面會顯示網址與 QR Code（預設埠 8630）。
使用同一個網路的電腦、平板用瀏覽器開網址，用本系統的帳號登入；畫面、資料、權限與桌面版相同。
檔案匯入舊網頁、匯入備份從瀏覽器上傳；匯出備份、平台進度 Excel 會下載到瀏覽器。語音教學在瀏覽器播放。
不提供備份與還原、版本更新、資料庫設定（只在那台電腦操作）。
停止關掉開關，或關閉那台電腦上的專案彙整，線上版會一起停止。
