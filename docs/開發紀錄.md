## 2026-11-22　v1.1.0（線上版）

線上版有兩種，都做：

1. **GitHub Pages 公開線上版**（https://achir1015.github.io/zms-projects/app/）
   - docs/app/index.html：純網頁，讀 docs/data/projects.json（公開專案）與 readmes.json（點開明細才載入）。
     搜尋、排序、篩選（發佈版本／App Store／Play／影片／線上版）、分類頁簽、卡片與平台進度總表、明細（影片播放、
     下載檔、平台進度、README 用 marked＋DOMPurify 顯示，相對路徑圖片改成 raw.githubusercontent）。
   - 影片：GitHub user-attachments 與 .mp4 直接 `<video>` 播放（外站可播，已實測）；YouTube 影片／播放清單用 nocookie 嵌入；其他開網頁。
   - 「即時更新」：瀏覽器直接呼叫 GitHub 公開 API（不需登入）更新星星數、說明、更新時間、新專案。
   - 資料來源：桌面版「彙整 GitHub → 發佈線上版」（hub.publish_online：Git Data API 一次 commit 兩個檔到
     sys_company.pages_repo 的 docs/data/，Token 需 Contents 寫入權限）；或 `tools/make_pages.py --data [--installed]`。
     公開資料只含非私人專案，不含便利貼備註、待辦、負責人（tests/test_hub.py::test_public_snapshot）。
   - docs/index.html：介紹頁＋6 課語音教學（lessons.json、voice/）＋公司內線上版說明＋下載。
2. **公司內的線上版**（zp/webserve.py）：版本更新與捷徑頁的開關（SYS 維護權限），用同一支程式另開網頁模式子程序
   （ZP_WEB_PORT 預設 8630、ZP_WEB_HOST=0.0.0.0、ZP_WEB_CHILD=1），顯示區網網址＋QR Code；子程序直接連桌面版的資料庫，
   桌面版關閉時一起停止。網頁版：隱藏備份還原、版本更新、資料庫設定；不能建立第一個管理員；語音用 flet_audio 在瀏覽器播放
   （Ctx.say_help／stop_voice）；匯入改上傳（Ctx.pick_bytes）、匯出改下載（Ctx.save_download）。
   - 打包要 `--collect-all=flet_web --collect-all=flet_audio --collect-submodules=uvicorn --hidden-import qrcode`；
     已用打包後的 exe 實測區網 IP 登入與語音。
- 資料庫升級 v2：sys_company 加 pages_repo、pages_at（UPGRADES 用 ADD COLUMN IF NOT EXISTS）。
